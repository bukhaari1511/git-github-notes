# Git & GitHub Notes

A collection of notes, commands, and practical examples from my Git & GitHub learning journey.

## About

This project is my **Git & GitHub Bootcamp Capstone Project**. It documents the concepts, commands, and workflows I learned while practicing Git and GitHub throughout the bootcamp.

The project focuses on understanding Git version control and the collaboration workflows used by professional software developers and open-source contributors.

## Topics

* Version Control
* Git Basics
* Git Repositories
* Commits and Git History
* Branching and Merging
* Merge Conflicts
* Remote Repositories
* GitHub Collaboration
* Pull Requests
* Code Reviews
* Issues
* Open Source Workflows
* GitHub Actions

## Purpose

The purpose of this project is to build a practical reference for Git and GitHub while demonstrating a complete Git and GitHub workflow.

The project will demonstrate:

* Creating and initializing a Git repository
* Making meaningful commits
* Working with branches
* Pushing to GitHub
* Creating and reviewing Pull Requests
* Working with Issues
* Linking Issues to Pull Requests
* Using code reviews
* Automating checks with GitHub Actions
